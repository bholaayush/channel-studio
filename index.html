Channel Studio Privacy Policy

Last updated: 10 November 2026

Channel Studio is a private tool used only by its owner to manage the owner's own YouTube channels (FactLight, The Quiet Gaze and Eyes Of). It is not offered to the public.

What data it accesses

With the owner's permission, through Google's OAuth sign-in, Channel Studio uses the YouTube Data API and the YouTube Analytics API to read channel and video statistics, upload videos, and manage the captions, thumbnails, playlists and comments of the owner's own channels.

How the data is stored

Sign-in tokens and any downloaded statistics are stored only on the owner's own computer. Nothing is stored on any server run by Channel Studio, because there isn't one.

Sharing

Channel Studio does not sell, share or transfer any data to third parties. It does not use the data for advertising.

Google API Services

Channel Studio's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. Use of YouTube data is also subject to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking it deletes nothing from YouTube. It only stops the tool from connecting.
